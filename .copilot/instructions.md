# Global Copilot Instructions

## Goal
Write clean, consistent, and reusable code.

---

## Rules
- Always write readable code (no clever shortcuts)
- Reuse logic if it already exists — do not duplicate
- Keep code modular (separate functions, not one big script)
- Always handle errors clearly
- Do not hardcode file paths or inputs
- Code must work for any user running it

---

## Input Rules
- Input must be dynamic (arguments or config)
- No hardcoded paths

---

## Output Rules
- All outputs must go into `/output` folder
- Output files must include timestamps in filename

---

## Code Quality
- Code must follow linting rules
- Code must be clean and structured

---

## Priority
1. Task-specific instructions
2. Language instructions
3. These global rules
